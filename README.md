# Диана на велосипеде

2D-раннер в духе «динозаврика» из Chrome: девочка Диана едет на велосипеде слева направо и перепрыгивает через конусы, камни, ящики, лужи и кусты.

- **Прыжок** — тап по экрану, клик мышью, пробел или стрелка вверх.
- Скорость постепенно растёт, звёздочки в воздухе дают +10 очков.
- Иногда на дорожке появляется мама Вика. Перепрыгнешь через неё — она крикнет «Дианка, молодец!» (+20 очков).
- Рекорд сохраняется в браузере.

Чтобы играть, откройте `index.html` в браузере (работает и на телефоне).
