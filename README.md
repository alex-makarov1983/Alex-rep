# Теннис вдвоём

Теннис с видом сверху для одного или двух игроков. Перед матчем каждый собирает своего персонажа.

Откройте `index.html` в браузере, удобнее всего на телефоне или планшете.

## Персонажи
В редакторе можно выбрать причёску (короткие, ёжик, пучок, хвостик, косички, кудри, длинные, ирокез), цвет волос, одежду (футболка, майка, полоски, платье, плащ) и её цвет, аксессуар (кепка, повязка, бантик), цвет кожи, цвет ракетки и имя. Кнопка «Случайно» собирает персонажа наугад. Персонажи сохраняются в браузере.

## Управление
- Каждый игрок управляет своей половиной экрана: один верхней, другой нижней.
- **Проведите пальцем** влево или вправо, чтобы подвинуть игрока под мяч.
- **Тапните**, когда мяч подлетит к игроку, чтобы его отбить. Тап нужен и для подачи.
- Клавиатура: нижний игрок — `A`/`D` и `W` (или пробел), верхний — `←`/`→` и `↓` (или Enter).

Можно играть вдвоём или против компьютера. Игра идёт до 7 очков.

# Теннисный тренер

`coach/index.html` — приложение для разбора техники по видео. Загрузите ролик своих ударов и получите оценку по элементам: что получается, что исправить, подсказки в формулировках тренеров и упражнения с партнёром. Каждый разбор сохраняется, так что видно прогресс, текущий уровень и слабые места.

Два уровня разбора:
- **По позе (бесплатно, на устройстве).** Модель MediaPipe Pose находит 33 точки тела 15 раз в секунду. Видео никуда не отправляется. Удары находятся по пикам скорости кистей; сбои модели, например перескок на партнёра, отбрасываются.
  - **Удары с отскока** оцениваются по семи элементам: разворот плеч, сгибание коленей, точка удара перед телом, работа руки, проводка, неподвижная голова, стойка.
  - **Подача** оценивается по шести: присед в трофи-позиции, высота точки удара, прямая рука, подбрасывающая рука, толчок ногами, завершение.
  - При съёмке сзади приложение это замечает, считает углы суставов по 3D-точкам и не оценивает то, что сзади не видно: точку удара, положение головы и уровень по позе.
- **Глубокий разбор ИИ (Claude, нужен ключ API Anthropic).** По каждому найденному движению в Claude уходят три кадра, обрезанные вокруг игрока: замах, контакт и завершение. Claude отсеивает ложные срабатывания, определяет тип удара и хват, называет 2–3 главных приоритета с установками и сравнением с профессионалами и подбирает упражнения с партнёром. Ответ приходит в JSON по строгой схеме. Один разбор стоит примерно 5–15 центов.

В профиле указываются имя, уровень, ведущая рука и тип бэкхенда. Там же хранится ключ API: он остаётся только в этом браузере и отправляется только в Anthropic.

Лучше всего снимать сбоку, на уровне пояса, так чтобы игрок был виден целиком. Если снимаете сзади, ставьте камеру ближе.

## Нарезка длинных видео

Если записей много (часы видео в телефоне или на YouTube), их удобно сначала нарезать программой `coach/tools/cut_strokes.py` на компьютере. Она оставляет только удары игрока у камеры, а остальное выбрасывает: паузы, сбор мячей, удары партнёра. Видео пережимается в 720p, так что из гигабайтов получаются десятки мегабайт.

Как программа находит удары:
1. **По звуку.** Удар ракеткой по мячу — короткий громкий щелчок. Это быстро даже для часовых записей.
2. **Отбор ударов игрока у камеры.** Щелчки дают и удары партнёра, и отскоки мяча, поэтому каждый щелчок проверяется:
   - `ai` — по умолчанию, если задан ключ `ANTHROPIC_API_KEY`. Claude смотрит на три кадра вокруг щелчка и решает, бьёт ли ближний игрок. Это точнее всего. Стоит примерно 0.25 цента за щелчок, то есть несколько долларов за час непрерывной игры.
   - `pose` — проверка позой MediaPipe, бесплатно. Надёжна, только если игрок крупный в кадре. При съёмке сзади издалека она почти ничего не отсеивает.
   - `none` — оставить все щелчки.
3. **Склейка.** Вокруг каждого удара вырезается фрагмент 2.2 с (удар на 1.3 с). Фрагменты склеиваются в ролики по 30 ударов: `<имя>_strokes_s2.2_h1.3.mp4`. По имени файла приложение знает, где удары. С флагом `--rallies` дополнительно сохраняется вся игра без пауз между розыгрышами.

### Установка (один раз)

- **macOS:** `brew install ffmpeg python`
- **Windows:** `winget install ffmpeg Python.Python.3.12`

Затем:

```
pip install numpy anthropic mediapipe yt-dlp
```

### Запуск

```
export ANTHROPIC_API_KEY=sk-ant-...            # Windows: set ANTHROPIC_API_KEY=sk-ant-...
python3 coach/tools/cut_strokes.py ~/Videos/tennis -o ~/Videos/vika_strokes
python3 coach/tools/cut_strokes.py "https://www.youtube.com/watch?v=..." -o ~/Videos/vika_strokes
```

- На вход подходят файлы, папки (обходятся вместе с вложенными) и ссылки на YouTube, включая плейлисты. Ролики с YouTube скачиваются через yt-dlp не выше 1080p; качайте только свои видео.
- Для каждого исходника рядом сохраняется `<имя>_strokes.json`: где в исходнике был каждый удар.

### Как передать нарезку в приложение

Скопируйте ролики `*_strokes_*.mp4` на телефон: AirDrop, «Файлы» / iCloud Drive или Google Drive. В приложении нажмите «Загрузить видео» и выберите один или несколько роликов. Удары из всех выбранных файлов сводятся в один разбор, а глубокий разбор ИИ берёт по 12 ударов равномерно из всех файлов.

Код:
- `coach/knowledge.js` — метрики, подсказки, упражнения, уровни;
- `coach/analysis.js` — разбор по позе;
- `coach/ai.js` — глубокий разбор через Claude;
- `coach/app.js` — интерфейс;
- `coach/tools/cut_strokes.py` — нарезка длинных видео.

Проверки: `node --test coach/test/*.test.js` и `python3 -m unittest discover coach/test`.
