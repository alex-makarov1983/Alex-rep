# Диана на велосипеде

2D-раннер в духе «динозаврика» из Chrome: девочка Диана едет на велосипеде слева направо и перепрыгивает через конусы, камни, ящики, лужи и кусты.

- **Прыжок** — тап по экрану, клик мышью, пробел или стрелка вверх.
- Скорость постепенно растёт, звёздочки в воздухе дают +10 очков.
- Иногда на дорожке появляется мама Вика. Перепрыгнешь через неё — она крикнет «Дианка, молодец!» (+20 очков).
- Рекорд сохраняется в браузере.

Чтобы играть, откройте `index.html` в браузере (работает и на телефоне).

# Угадай страну

Викторина по карте мира для 1–6 игроков (`geo-quiz/index.html`). На карте подсвечивается случайная страна, игроки по очереди называют её.

- На ход одна попытка ответа. Небольшие опечатки прощаются, принимаются и альтернативные названия (США, ЮАР, Белоруссия…).
- Не знаешь — открой до трёх подсказок: регион и население, столица, интересный факт с первой буквой названия.
- Побеждает тот, кто угадал больше стран; при равенстве — тот, кто взял меньше подсказок.
- 166 стран. Контуры — Natural Earth 1:110m, собраны в `geo-quiz/map-data.js` скриптом `geo-quiz/tools/build-map.mjs`, так что игра работает без интернета.
